# Clean Code (Código Limpo)

**Carregar**: `view .claude/skills/clean-code/SKILL.md`

---

## Descrição

Princípios de Código Limpo (Clean Code) com exemplos em Java: DRY, KISS, YAGNI, convenções de nomenclatura, design de
funções, code smells (maus cheiros no código) e técnicas de refatoração.

---

## Casos de Uso

- "Limpe este código" / "Clean this code"
- "Refatore este método" / "Refactor this method"
- "Melhore a legibilidade" / "Improve readability"
- "Esta função está muito longa" / "This function is too long"
- "Qual nome devo dar a esta variável?" / "What should I name this variable?"
- "Este código está muito complexo?" / "Is this code too complex?"

---

## Exemplos

```
> view .claude/skills/clean-code/SKILL.md
> "Este método tem 100 linhas, me ajude a refatorar"
→ Identifica code smells, sugere Extract Method (Extrair Método), Guard Clauses (Cláusulas de Guarda)
```

---

## Princípios Abordados

| Princípio | Pergunta-chave                                    |
|-----------|---------------------------------------------------|
| **DRY**   | Esta lógica está duplicada em outro lugar?        |
| **KISS**  | Existe uma maneira mais simples?                  |
| **YAGNI** | Precisamos disso agora ou "apenas por precaução"? |

---

## Tópicos

- Convenções de nomenclatura (variáveis, métodos, classes)
- Design de funções (tamanho, parâmetros, abstração)
- Comentários (quando são bons, quando são ruins)
- Detecção de code smells (maus cheiros no código)
- Técnicas de refatoração
